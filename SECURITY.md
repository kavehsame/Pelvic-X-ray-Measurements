# Security and responsible reporting

The web application processes selected files in the browser. The Slicer extension
processes them in the local Slicer session. Neither edition requires uploading
images or annotations to this project.

Report suspected vulnerabilities through the repository's **Security → Report a
vulnerability** option when available. If private reporting is unavailable, open
an issue asking for a private contact without disclosing exploit details or data.
Never include patient information, credentials or sensitive files in a public issue.

Include the edition, software version, browser or Slicer version and a synthetic
reproduction if possible. There is no guaranteed response or support period. Use
the latest published version and keep the browser or Slicer installation current.

This is research software, not a medical device or a clinical decision system.
