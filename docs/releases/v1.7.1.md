# Pelvic X-ray Measurements 1.7.1

- **Go to image** sits directly below the filename and image count in the web
  sidebar. Type an image number and press Enter or select **Go**. The app holds
  working annotations in the tab as you move between images.
- Moving near an editable landmark shows a focus ring. Where points overlap,
  click to cycle through them and read the label to identify the selected point.
  Dragging keeps that point selected until you release it.
- The hand cursor appears only while dragging the radiograph to pan. At high
  magnification, the viewer displays source pixels without smoothing, including
  during a pan.

The Slicer extension uses the same version number. Read the [web manual](../web-manual.md)
and [software testing methods](../testing.md).

**Research use only. This software is not a medical device.** A validation study
against established medical software is in progress.
