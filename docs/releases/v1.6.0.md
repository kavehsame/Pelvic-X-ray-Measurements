# Pelvic X-ray Measurements 1.6.0

This release provides the Slicer extension and a browser-based web application
for editable, calibrated pelvic radiograph research.

**Research use only. This software is not a medical device.** It is not intended
for diagnosis, treatment planning or other clinical decision-making.

## Use the tool

- [Open the web app](https://kavehsame.github.io/Pelvic-X-ray-Measurements/app/).
  Select Start, choose local images and export to the computer. Images and
  annotations are not uploaded to the host.
- Download **PelvicXrayMeasurements_1.6.0_Slicer_extension.zip** to add the module to
  an existing Slicer installation. This is a complete scripted-module bundle,
  including models, not an Extensions Manager installer.
- Download **PelvicXrayMeasurements_1.6.0_web.zip** only to host a separate copy of
  the web app. Website visitors do not need this ZIP.
- **SHA256SUMS.txt** identifies the exact download files. GitHub's source archives
  are for development and omit separately distributed runtime and model assets.

## Included workflows

Both editions provide native and implant head fitting, shaft and neck axes,
acetabular angles, offsets, leg-length discrepancy, morphology indices, cup opening
geometry, pelvic and shaft contours, shared landmarks and custom measurements.
Smart Point Placement suggests editable feature groups after the required anchors
are placed. CSV, image and scene exports preserve research results and allow resume.

The web app includes live editing, panning during placement, Shift-drag window
adjustment and verified caching of its software package. It reads common image
formats and supported single-radiograph medical formats. Chrome or Edge offers the
most convenient folder exports. Read the edition-specific manual for limitations.

## Evidence and validation

The [software review](https://kavehsame.github.io/Pelvic-X-ray-Measurements/tests/)
includes unit tests, the full synthetic measurement replay and interaction checks.
Generated results are kept in source and on the documentation website, not inside
the downloadable product bundles.

A validation study is being performed to compare the tool with established medical
software. This is separate from the automated software checks. Completed clinical
validation or medical-device approval is not claimed.
