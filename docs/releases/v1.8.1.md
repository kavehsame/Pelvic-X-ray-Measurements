# Pelvic X-ray Measurements 1.8.1

The web app and 3D Slicer extension now identify each placed cup and stem on the exported PNG. Each label gives the patient side, implant family and catalogue size. Implant labels appear even when numeric measurement values are hidden.

The CSV records the same information and the template ID. Look for rows such as `Left_Planning_Cup_Family` and `Left_Planning_Cup_Size`. The resection tools still draw the cut on the image. Their landmarks, coordinates, segment lengths and total length remain available in the CSV. Cut lengths have been removed from the results panel and PNG summary.

Both editions can reopen earlier CSVs, including files with reordered rows or columns. For a 1.8.0 plan, PXM looks up the saved implant ID in the catalogue. Reimport the matching pack to recover labels for an older custom implant. Files saved with 1.8.1 retain the labels even if that pack is later unavailable.
