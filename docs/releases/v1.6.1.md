# Pelvic X-ray Measurements 1.6.1

This update changes web startup and explains network restrictions. Measurement
definitions, annotation tools, Smart Point Placement models and exports retain
their existing behaviour. The Slicer edition receives the matching version label.

- Downloads the web runtime as small, correctly labelled JSON components.
- Compresses the package before encoding to keep the total component download
  below the previous binary-package size.
- Verifies every component and the complete package, caches verified software,
  reuses completed components after an interrupted download and retries transient
  failures once.
- Shows the response status and download details when preparation fails.
- Adds a landing-page notice that some restricted networks, including hospital
  networks, may prevent the app from starting.

The runtime still contains its existing Python library packages. A network that
blocks their contents may require IT approval. The update has not been accepted
on any particular hospital network; see [network access](../network-access.md).

[Open the website](https://kavehsame.github.io/Pelvic-X-ray-Measurements/),
read the [manuals](https://kavehsame.github.io/Pelvic-X-ray-Measurements/manuals.html)
or review the [software checks](https://kavehsame.github.io/Pelvic-X-ray-Measurements/tests/).
The Slicer extension ZIP includes the required models. The web ZIP is for hosting
a separate copy; ordinary website visitors do not need it. **SHA256SUMS.txt**
records the product download checksums. Earlier releases remain available.

**Research use only. This software is not a medical device.** It is not intended
for diagnosis, treatment planning or other clinical decision-making. The validation
study against established medical software remains separate from software checks.
