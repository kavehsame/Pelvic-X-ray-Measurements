# Pelvic X-ray Measurements 1.8.0

The web app and the 3D Slicer extension now include hip templating. In **Planning**, place a straight or stepped femoral neck cut and move or rotate the retained fragment. PXM can outline the fragment automatically, or you can trace its boundary yourself.

- Choose from 794 AP implant entries across 51 families. The catalogue uses cropped, recoloured Medacta and Mathys drawings from the OsiriX Hip Arthroplasty Templating Plugin 3.6.5. Each entry retains its source scale, pivot and side. Use the rotation handle or enter an angle.
- Select **Import overlay pack…** to add your own AP outlines for the session. **How It Works** explains the file format, drawing scale and calibration.
- In the post-op section, fit the outer cup shell after placing the implant head. The distance between the two centres gives a **single-film estimate of inlay wear**. A rate of wear requires measurements over time.
- Both editions can resume annotations from earlier PXM CSVs and recognise saved points when the rows or columns have been reordered.

Download **PelvicXrayMeasurements_1.8.0_Slicer_extension.zip** for an existing Slicer installation. **PelvicXrayMeasurements_1.8.0_web.zip** contains the complete app for self-hosting. Both include the processed overlays, catalogue and Smart Point Placement models. **SHA256SUMS.txt** lists the checksums. The website caches its software on first use and processes images on the user's device.

**Research use only. This software is not a medical device.** A validation study comparing PXM with established medical software is in progress.
