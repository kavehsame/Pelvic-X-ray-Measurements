# Pelvic X-ray Measurements 1.7.0

This release improves exported figures and contour placement in the web app and
adds two acetabular wall contours to both editions.

- PNG annotations and measurement text are rendered at the final export
  resolution. Small source radiographs fill the enlarged frame, with their
  proportions preserved. The minimum long edge is 2,048 pixels for ordinary
  image proportions. Enlargement does not add anatomical detail.
- The web PNG measurement box sits at the bottom centre. It remains translucent,
  with annotation colours preserved over it.
- Anterior Acetabular Wall and Posterior Acetabular Wall appear directly below
  Acetabular Roof (Sourcil). They use yellow and pink and the existing bilateral
  contour workflow, including edge attraction, Hide, editing and coordinate export.
- The dashed continuation previews contour curvature towards the pointer while
  keeping straight-line tools' existing behaviour.
- Morphology-index hover help opens larger and fits the available screen.
- A repository agent entry point and detailed technical handover support future
  maintenance. The synthetic CSV replay includes both new walls on both sides.

The existing measurement definitions and Smart Point Placement weights are
unchanged. Models remain at version 1.6.0. The web app retains local processing,
verified cached startup and the restricted-network notice.

Read the [manuals](https://kavehsame.github.io/Pelvic-X-ray-Measurements/manuals.html)
and [software check methods](https://kavehsame.github.io/Pelvic-X-ray-Measurements/docs/testing.html).
The Slicer extension ZIP includes the models. The web ZIP is for hosting a copy;
website visitors do not need to download it. Product bundles exclude generated
test results. Their hashes are recorded in `SHA256SUMS.txt`.

**Research use only. This software is not a medical device.** It is not intended
for diagnosis, treatment planning or other clinical decision-making. A validation
study against established medical software is in progress separately from the
software tests.
