# Support

Read the [web manual](docs/web-manual.md) or
[Slicer manual](extension_source/SlicerPelvicXrayMeasurements/documentation.md) first.
For a reproducible problem, open a GitHub issue and include:

- The edition and version, operating system and browser or Slicer version.
- The sequence of actions, expected result and observed result.
- A synthetic example or a screenshot without confidential information, if useful.

Do not attach patient radiographs, identifying filenames or clinical exports.
Smart Point Placement suggestions need manual review; an unexpected suggestion
does not by itself establish a calculation defect. Distinguish point placement,
measurement construction and exported numerical results in the report.

Support is provided as time permits. The software is supplied without warranty.
